NORTHSTAR CUSTOMER SUPPORT

Remote help.
You're in control.

When Austin is ready to help, use RustDesk to share your screen and approve remote control of your computer.

This page helps you get set up. The support session takes place in the RustDesk app.

1. Download RustDesk

Use the official RustDesk release page on GitHub. In its download table, choose your computer's operating system. The installer comes directly from RustDesk's official repository.

Official RustDesk downloads ↗

Opens the latest release in a new tab. No GitHub account is needed to download.

Mac

Choose the Mac download: AArch64 (ARM64) for Apple silicon, or x86-64 for Intel.

Check Apple menu → About This Mac: “Chip” identifies Apple silicon; “Processor” identifies Intel.

Open the .dmg and drag RustDesk into Applications, then open it.

Windows

For most PCs, choose the Windows x86-64 EXE. Use ARM64 only if your PC has an ARM processor.

Open the downloaded .exe and follow the app's prompts. Austin can help if you're unsure which download to choose.

2. Approve your session

  1. Keep RustDesk open and give Austin your RustDesk ID over your existing call or conversation.
  2. When Austin connects, review the request and accept the session. Allow screen viewing and keyboard/mouse control for the work you want help with.
  3. Stay at your computer while Austin helps. You can disconnect at any time in RustDesk.

For this support visit, use session approval. You don't need to set a permanent password or enable unattended access.

On a Mac: allow screen sharing and control

Open System Settings → Privacy & Security and enable RustDesk in:

  • Screen Recording (or Screen & System Audio Recording), so Austin can see your screen.
  • Accessibility, so Austin can use the mouse and keyboard.
  • Input Monitoring, if RustDesk requests it or input still doesn't work.

Follow any prompt to quit and reopen RustDesk after changing permissions.

Official Mac setup guide ↗

3. Finish and disconnect

End the session in RustDesk when the work is complete, then quit the app. You can remove RustDesk and revoke its Mac permissions if you no longer need it.
