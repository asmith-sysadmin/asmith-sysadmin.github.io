01 / INSTALLATION

Install on your Windows computer

  1. Use the download page to choose Windows. Check the version and requirements: Windows 10 or 11, Intel/AMD 64-bit, .NET Framework 4.8 or newer.
  2. Download the installer. You can use the page’s Check your file tool to compare its SHA-256 checksum locally. A match verifies file contents against the published release; it does not certify the publisher or replace a digital signature.
  3. Run Northstar-Punch-Clock-Setup-0.3.0-x64.exe. The current demo is unsigned, so Windows may warn about an unknown publisher. If the file’s source or checksum is unexpected, stop and contact your administrator.
  4. Choose English or Spanish for the setup wizard. The app interface currently uses English.
  5. Continue through Welcome and the computer compatibility screen. Select the shortcuts you want and the installation folder.
  6. Choose Install, then Open Punch Clock on the Finish screen. Required offline runtime components are bundled.

Use the same Windows account for the shared workplace clock. Other Windows profiles and computers have separate local databases. No online account or activation code is needed.

LINUX DEMO

Install the Kali Linux demo

  1. Select Linux on the download page and download the AMD64 .deb package. Compare its checksum before installing.
  2. In a terminal in the download folder, run sudo apt install ./Northstar-Punch-Clock-0.3.0-7-kali-amd64.deb. Internet may be required to install dependencies.
  3. Launch Northstar Punch Clock from the application menu as your regular user. Do not launch the app with sudo.
  4. Follow the same organization, manager, and employee setup below.

Targets Ubuntu 22.04/24.04 and compatible Debian-family desktops with the required Qt packages. GUI testing is pending; compatibility with every distribution is not established. Records are local to the Linux user under ~/.local/share/Northstar/PunchClock. Removing the package retains user records.

02 / FIRST-TIME SETUP

Make it your organization’s clock

  1. Enter the business or organization name. Upload a PNG or JPEG logo if desired: up to 2 MB and 4096 × 4096 pixels.
  2. Choose a color preset or your own accent and background colors. Choose Comfortable, Compact, or Large buttons, then select Continue.
  3. Enter the first manager’s name and username. Usernames use 3–32 letters, numbers, periods, underscores, or hyphens; begin with a letter or number.
  4. Create and confirm a manager password of at least 12 characters, then choose Finish setup. Store this password securely.
  5. Open Employees. Add each employee’s full name, optional department, and a personal 6–8 digit PIN.
  6. Use Print badge in the employee directory to issue each person’s barcode badge. Keep PINs separate from the printed badges.
  7. Open Managers if another person needs manager access. Give each manager a separate username and password.
  8. Select Lock & open employee clock before leaving the computer available to staff.

After setup, managers can change branding through Appearance → Save appearance. First-time setup is not repeated on every launch.

03 / EMPLOYEE QUICK GUIDE

Badge. PIN. Record your time.

Clock in

  1. Click Badge code, then scan your own barcode with a USB scanner or enter your badge code.
  2. Enter your personal PIN and choose Employee sign in.
  3. Choose Clock in. Read the policy reminder, then select Record clock in.
  4. The app signs you out after the punch. Check the success message before leaving.

Lunch and clock out

  1. Sign in again and choose Start lunch when starting lunch.
  2. When you return, sign in and choose End lunch.
  3. At the end of your shift, sign in and choose Clock out. Confirm with Record clock out.

Early lunch is recorded and flagged for manager review; it is not blocked. Follow your organization’s approved break policy. Lunch is not deducted automatically.

Change your PIN

Sign in, choose Change PIN, enter your current PIN, then enter and confirm a new 6–8 digit PIN. Select Save new PIN. You will be signed out; use the new PIN next time. If you forgot your PIN, ask a manager for a reset.

Use only your own badge and PIN. You see only your own clock controls. Employee sessions end after a punch or after two minutes; use Sign out whenever needed.

04 / MANAGER GUIDE

Manage the team and review punches

  1. From the staff clock, select Manager sign in and enter your manager username and password.
  2. Use Overview to see who is working, on lunch, or clocked out.
  3. Under Employees, add staff, print badges, reset a forgotten PIN, or deactivate an employee. Deactivation preserves existing records.
  4. Under Punch records, filter by employee and inspect review notes. The screen shows the latest 5,000 events; Export CSV includes all events.
  5. Under Managers, create separate manager accounts, reset another manager’s password, or change active status. All managers have full manager access. At least one must remain active.
  6. Use Settings & backup → Record a manager exception to choose an employee and action and supply a reason. This records the current time; it does not backdate or rewrite old punches.
  7. Change your own password under Settings & backup → Change manager password, supplying the current password and confirming the new one.
  8. Choose Lock & open employee clock when finished. Manager tools also lock after inactivity.

Review actual events before payroll. CSV is an event export, not calculated payroll. Investigate missed punches and time-change warnings through your organization’s documented process.

05 / RECORDS & BACKUPS

Keep a separate copy

  1. Sign in as manager and open Settings & backup.
  2. Choose Save database backup and select a safe location, such as a managed backup drive. A CSV export does not replace the database backup.
  3. Use Show data location to identify the active database. A new installation normally uses %LOCALAPPDATA%\Northstar\PunchClock\punch-clock.sqlite.
  4. Before installing a future update, save a backup and close Punch Clock. Use an approved later installer; setup backs up existing data separately from program files.
  5. Keep backup files private: they contain employee accounts and punch records. The app does not synchronize records to other computers or to the download website.

There is no in-app restore wizard in this version. Have your administrator review and perform a restore with the app closed. Do not delete the database to fix a login problem. Uninstalling the program keeps local employee data.

06 / TROUBLESHOOTING

When something needs attention

The app does not open
Look for an existing Punch Clock window first. If startup fails, capture the exact message. Startup diagnostics are normally saved to %LOCALAPPDATA%\Northstar\PunchClock\startup-error.log. Share only relevant errors; never send passwords, PINs, or a live database through a public support channel.
A badge does not scan
Click the Badge code field first. Check that the scanner works as a keyboard and the badge belongs to an active employee. Manual badge entry is available. Camera scanning is not included in this desktop version.
A PIN is rejected
Check the badge and PIN combination. Repeated failures may temporarily lock sign-in. A manager can reset the employee PIN; the employee can change it after signing in.
The displayed time is wrong
Ask the administrator to check Windows date/time and time synchronization. This app displays Central Time. Clock changes can flag events for manager review; do not change the clock to alter recorded work time.
Another computer has no employee records
Each installation is local. Data does not automatically transfer between Windows accounts or devices. Contact your administrator to plan migration or a reviewed backup restore.
Setup reports a missing component
Use the complete approved installer, confirm Windows x64 and .NET Framework 4.8 or newer, and send the exact error to your administrator. Do not download replacement runtime files from an unfamiliar website.
